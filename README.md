# 📝 Listful To-Do List

**Listful** is a minimalist to-do list web application built with HTML, CSS, and JavaScript. It's designed for simplicity: just add a task, press enter, check it off when done, or delete it when no longer needed.

---

## 💡 Features

- ✅ Add a new task by typing and pressing **Enter**
- ✔️ Mark tasks as complete
- ❌ Delete tasks when you're done with them
- 🧼 Clean, responsive user interface

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---

## 🚀 Getting Started

To run Listful locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/paigehai/ListfulToDoList.git
   ```

2. Navigate to the project folder:
   ```bash
   cd ListfulToDoList
   ```

3. Open `index.html` in your browser:
   - Double-click `index.html` **or**
   - Use Live Server in your code editor
